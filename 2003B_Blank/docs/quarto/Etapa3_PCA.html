Etapa 3 - Análisis de Componentes Principales

Justificación del PCA

El PCA se utilizará como técnica de interdependencia para identificar patrones comunes entre los contaminantes, las variables meteorológicas y el NDVI, y resumir la información de varias variables correlacionadas en un número menor de componentes.

Adecuación del PCA

# Matriz de correlaciones
R <- cor(datos_pca_completos)

# Número de observaciones y variables
n <- nrow(datos_pca_completos)
p <- ncol(datos_pca_completos)

# KMO
invR <- solve(R)
parciales <- -cov2cor(invR)
diag(parciales) <- 0

R2 <- R^2
diag(R2) <- 0

P2 <- parciales^2

kmo <- sum(R2) / (sum(R2) + sum(P2))

# Prueba de Bartlett
chi2 <- -(n - 1 - (2 * p + 5) / 6) * log(det(R))
gl <- p * (p - 1) / 2
p_bartlett <- pchisq(chi2, df = gl, lower.tail = FALSE)

cat("KMO:", round(kmo, 3), "\n")

Resultados e interpretación

La adecuación de los datos para el PCA se revisó mediante el índice KMO y la prueba de esfericidad de Bartlett. Se obtuvo un KMO de 0.627, lo que muestra una adecuación limitada, aunque suficiente para utilizar el PCA con un propósito exploratorio. La prueba de Bartlett resultó significativa (\(p < 0.001\)), por lo que se rechaza la hipótesis de que las variables no están correlacionadas.

El PCA se estimó con 155 observaciones completas de las 360 disponibles, debido principalmente a la cantidad de valores faltantes de PM\(_{2.5}\). Por esta razón, los resultados se interpretan con un alcance exploratorio.

Se conservaron 3 componentes principales debido a que presentaron autovalores mayores a 1. En conjunto explican el 65.28% de la variabilidad total: PC1 explica 30.24%, PC2 21.42% y PC3 13.63%.

El PC1 contrapone PM\(_{10}\), PM\(_{2.5}\) y NO\(_2\) (cargas negativas) con la temperatura, la velocidad del viento y el O\(_3\) (cargas positivas): representa el ciclo estacional, en el que los meses cálidos y con más viento tienen menos partículas y NO\(_2\) pero más ozono. El PC2 está asociado con la humedad relativa y el NDVI a 2000 m (positivas) frente al O\(_3\) y la velocidad del viento (negativas), por lo que representa un componente de vegetación y humedad. Finalmente, el PC3 está dominado por la precipitación, con una participación de NO\(_2\) y una carga negativa del NDVI. El NDVI no carga de forma importante en el PC1, el que concentra a los contaminantes, lo que coincide con la débil relación entre vegetación y contaminación observada en la regresión.
